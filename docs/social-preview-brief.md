# Changelog social preview brief

Use one 1200 by 630 pixel landscape image for the changelog route.

- Show the exact text `GoTreeSitter` and `Changelog`.
- Use the Paper & Ink visual system from `docs/visual-system.md`.
- Build the image from warm paper, black technical lines, hard offset shadows,
  and the existing violet, cyan, green, yellow, and pink accents.
- Use an abstract syntax-tree timeline as the central visual. Connect a tagged
  release block to smaller change nodes.
- Keep the composition legible at social-card size.
- Do not add a logo, version number, performance claim, source code, small
  body copy, gradient, photograph, watermark, or extra text.

Wire the image only when both required words are exact and clearly legible.
